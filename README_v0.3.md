# Access AI v0.3 — Adaptive Accessibility

Adds accessible first-run onboarding, vision and interaction preferences, voice-first blind mode, low-vision mode, larger controls, TalkBack-oriented instructions, and the ability to rerun setup.

Replace app.py, system_prompt.txt, and requirements.txt in the existing GitHub repository. Keep the existing OPENAI_API_KEY Streamlit secret.

Note: Streamlit is a browser prototype. Whole-screen touch exploration and custom haptic patterns are better implemented in the later native Android app using Android accessibility APIs.
